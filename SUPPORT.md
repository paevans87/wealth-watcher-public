# Support policy

Wealth Watcher is a self-hosted project maintained on a best-effort basis.

## In scope

- Reproducible defects in the current `main` branch.
- Documentation gaps and setup problems that can be reproduced without private data.
- Questions about the documented configuration and supported integrations.

## Out of scope

- Personal financial, tax, investment, or provider-account advice.
- Incidents caused by unsupported deployment changes, exposed services, or lost backups.
- Support requests that include credentials, private URLs, or personal financial data.

Open a safe, reproducible bug or feature request using the repository templates. Report security issues privately using [SECURITY.md](SECURITY.md).
