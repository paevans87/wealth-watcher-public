Your data, your boundary

Built to live with your setup.

Wealth Watcher is designed as a local-first application. Run the API, browser UI, and PostgreSQL database on a machine or trusted network you control. Optional provider integrations are read-only, and saved credentials are protected before they are stored.

This is an early-stage, single-user project. Keep it local unless you add the authentication and network controls needed for a public deployment.

Optional analytics applies only to this public landing page. Use the analytics preferences control in the footer to change your choice.

✓Docker Compose readyStart the API, UI, and database together.

✓Visible assumptionsForecasts show the inputs behind the projection.
