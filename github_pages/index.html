Your data, your boundary

Built to live with your setup.

WealthWatcher is designed as a local-first application. Run the API, browser UI, and PostgreSQL database on a machine or trusted network you control. Saved integration credentials are protected before they are stored.

This is an early-stage, single-user project. Keep it local unless you add the authentication and network controls needed for a public deployment.
