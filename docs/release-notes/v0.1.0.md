# Wealth Watcher v0.1.0

## Highlights

- Personal wealth tracking for cash, investments, pensions, property, and other assets.
- Dashboard, history, calendar, forecast, FIRE, and budget views.
- Optional Trading 212 and SnapTrade integrations with encrypted local credentials.
- Local/trusted-network Docker Compose deployment with persistent PostgreSQL data.

## Fixes

- Establishes the first public release baseline and the supported application release process.

## Upgrade notes

- This is the initial public release. New installations should follow the Docker Compose setup in the README.
- Keep the PostgreSQL volume and the configured ASP.NET Data Protection key directory backed up.

## Docker images

- Tagged API and web images are published to the GitHub Container Registry for this release.
- Updates are applied manually by pulling the release-tagged images and recreating the API and web services.
- The database image, PostgreSQL volume, configuration, and Data Protection keys are not replaced by an application update.

## Known issues

- The application is intended for local or trusted-network use and does not provide authentication or tenant isolation.
- Forecasts are illustrative estimates and are not financial advice.
